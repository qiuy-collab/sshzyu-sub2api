# SSHZYU 接入指南

此目录维护独立 `/docs/` 静态站点。技术正文保存在 `content.md`，原有接口、示例、教程截图与四个章节锚点保持兼容。

视觉方向：珍珠灰底色、白色阅读面、石墨文字和克制的蓝色选中态，与主站使用同一个原始 SVG Logo。正文优先可读性，不增加装饰性插画。

内容结构：精简品牌导航、对齐的四章节入口、单列技术正文、连续编号的操作步骤，以及可展开查看的教程截图。桌面目录常驻，手机目录通过按钮展开。代码块与表格独立横向滚动。

交互方向：快速的目录选中反馈、与阅读位置同步的顶部细进度条、轻量的截图展开；尊重减少动态效果偏好。

构建：在仓库根目录执行 `node web-docs/build.mjs`。不需要安装额外依赖；构建输出到 `web-docs/dist`，CSS、JS 和主站 Logo 使用内容哈希文件名。测试：`node --test web-docs/tests/build.test.mjs`。

只发布构建的 `index.html` 和新增 `assets`。部署保留服务器原有 `content.md` 与 `iamge/` 文件，目录名称兼容旧图片链接。先上传不可变资源，再原子替换首页；无须重载 Nginx 或重启任何容器。
